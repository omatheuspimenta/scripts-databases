# Technical Validation figures and tables

Supplementary Figures 3-17 and Supplementary Tables 2-32, added in response to
the reviewers' comments (Supplementary Figures 3-11 and Tables 2-12 for
reviewer #2, comment 2; Supplementary Figures 12-17 and Tables 13-26 for
reviewer #2, comment 4). Figures were generated by `scripts/make_figures.R` from `qc/tables/`. Each figure is written
in three formats — **PNG** (300 dpi, raster), **SVG** and **PDF** (both vector,
for journal submission and further editing).

Figure legends are in [`figure_legends.txt`](figure_legends.txt). Source data
for the figures are the `SupplementaryTable*.tsv` files in this directory.

Regenerate all of them with:

```bash
make_figures.R
```

### Font

Set to **Arial**. Real Arial is not distributable on Linux, so the figures are
rendered with **Liberation Sans**, which is metric-compatible with Arial —
identical advance widths, so glyph positions and line breaks match Arial
exactly. Practically:

- **PDF** embeds Liberation Sans (reported as `LiberationSans` by `pdffonts`).
- **SVG** declares `font-family: Arial, "Liberation Sans", Helvetica, sans-serif`,
  so opening it on a machine that has Arial — Windows, macOS, most journal
  production systems — renders in genuine Arial with no reflow.
- **PNG** is rasterised at 300 dpi, so the distinction does not apply.

To render with genuine Arial here instead, drop `Arial.ttf`, `Arial Bold.ttf`,
etc. into `~/.local/share/fonts` and point the `register_font()` call at them;
nothing else in the script needs to change.

### Colour

Colours come from a validated palette; `scripts/validate_palette.R` is a port of
the reference validator (this machine has no Node) and was checked against the
reference implementation's documented values before use — it reproduces them
exactly (worst adjacent CVD ΔE 9.1, normal-vision ΔE 19.6 in light mode).

- **Series blue `#2a78d6` / orange `#eb6834`** — passes every gate on all pairs
  (CVD ΔE 24.7, normal-vision ΔE 33.6, both above 3:1 contrast).
- **Status green / amber / red** in Fig 6 is the reserved state palette. Amber
  sits outside the categorical lightness band and below 3:1 contrast by design,
  so **every segment carries a printed percentage** and verdict is never
  conveyed by colour alone.
- Supplementary Figure 4 plots the raw distribution only: raw and trimmed densities are
  visually identical (trimming removes a median of 0.18% of reads), so drawing
  both would hide one series entirely behind the other. The before/after
  comparison is carried by Supplementary Figure 5.
